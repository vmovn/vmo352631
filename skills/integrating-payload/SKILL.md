# Integrating Payload

## Principle
Payload owns content, not art direction.

Use:
`Payload → typed query/adapter → original Mortar component`.

Homepage/strategic pages use fixed schema.
Generic page blocks are for real landing-page variability only.

Keep Payload Admin free of Mortar frontend runtime.
VI/EN localization starts at schema level.
