# VMO Mortar Agent Kit V2

Project constitution and source-aware implementation kit for rebuilding `vmo.vn` from the purchased Mortar Next.js template.

## Key principle
> Mortar owns Experience. Payload owns Content. VMO35 owns Meaning. VMO OS owns Execution.

## Why V2 exists
The first VMO/Vantora experiment proved that a CMS-first prompt can accidentally replace premium template components with generic blocks. V2 reverses the order: preserve the purchased experience first, then make it dynamic.

## Source facts audited
- Next.js `14.2.4`, React 18.
- Bootstrap 5 + large Mortar CSS.
- GSAP/ScrollTrigger/SplitText loaded globally.
- WOW, Swiper, animated cursor, modal video, ApexCharts and other interactions.
- 51 page routes.
- 86 component source files.
- 7 light homepage families plus dark variants.
- ~686 public assets, including 6 MP4 files.
- Root `layout.js` is currently a Client Component and applies Mortar runtime globally.

See `docs/MORTAR-SOURCE-INVENTORY.md`.

Copy this kit into the root of a fresh Mortar working repository. Keep the original purchased ZIP outside Git as a recovery source. Do not start with a “build everything” prompt.
