## Required language

- 0→1 Proof/Market Validation;
- 1→2 Repeatable Process;

Avoid positioning VMO as SaaS, AI platform, CRM vendor, software company or “Marketing 360”.

## Proof policy
Demo numbers/logos/testimonials/awards from Mortar are never published as VMO proof.
If no verified proof exists:
- hide the data;
- use a framework/explanation;
- show empty state;
- use qualitative copy without invented claims.

## Content fitting rule
When VMO copy is longer than Mortar demo copy:
1. rewrite shorter while preserving meaning;
2. use existing alternate Mortar component if better;
3. adjust responsive typography carefully;
4. only then request layout change.

Do not redesign because Vietnamese text is longer.
