# CODEX.md — Operator Contract

Use Codex for repo-wide engineering work:
- source audit and inventory;
- Next/React compatibility migration;
- route-group/runtime isolation;
- Payload CMS installation and schema;
- database/migrations;
- API/forms/jobs;
- tests/security/Docker;
- large refactors with clear acceptance gates.

Codex must read `AGENTS.md` first.

Codex must not:
- redesign Mortar;
- delete demo components as cleanup;
- replace effects for convenience without proving necessity;
- run beyond a visual acceptance gate without human approval.

Expected handoff after each Codex phase:
1. branch/commit;
2. verification report;
3. changed-file summary;
4. exact routes to inspect;
5. ZIP full code when requested by operator.
